# Machine-readable profiles

This directory contains implementation profiles that translate Trust & Life normative requirements into explicit machine-checkable pilot rules.

A profile is **not** a substitute for law, professional inspection, food-safety certification, or domain expertise. It defines what the Trust & Life reference evaluator can and cannot decide for a stated scope.

Profiles SHOULD contain stable requirement identifiers, source-standard mappings, blocking/advisory classification, minimum T-levels where relevant, acceptable evidence categories, independent-verification rules, incident policies, and public interpretation notes.

The first profile, `TL-FRESH-PRODUCE-001`, is deliberately a **pilot transparency baseline**. It is not a complete fresh-produce safety standard.
