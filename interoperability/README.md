# Interoperability

Trust & Life prefers established standards over proprietary lock-in.

Current profiles:

- `epcis-mapping.md` — GS1 EPCIS 2.0.1 / CBV 2.0.0 mapping direction.
- `vc-mapping.md` — W3C Verifiable Credentials Data Model 2.0 mapping direction.
- `crypto-federation.md` — v0.3 signing, key lifecycle, credential status, and registry federation profile.

The interoperability documents define integration directions and demonstration profiles. They do not imply certification or endorsement by the external standards organizations.
